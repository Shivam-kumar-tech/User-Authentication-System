🔐 User Authentication System
A simple yet secure User Authentication System built using Node.js and Express, featuring user registration, login, and access control for protected routes.

📌 Project Objective
This project implements a basic authentication system that allows users to:

✅ Sign up for an account

🔐 Log in securely with hashed passwords

🔓 Access protected pages only after successful login

🚫 Prevent unauthorized access to restricted routes


🛠️ Tech Stack

- **Frontend:**
  - HTML
  - CSS
  - JavaScript

- **Backend:**
  - `
  - `Express.js`

- **Authentication:**
  - Express Sessions (for maintaining user sessions)
  - `bcrypt` for secure password hashing

🚀 Features
User Registration with form validation

Secure Login with password hashing (bcrypt)

Protected routes (middleware-based access control)

Session management

Logout functionality
